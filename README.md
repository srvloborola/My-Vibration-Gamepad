# My Vibration Gamepad

**Current version: 0.9**

Gamepad vibration and right-stick camera support for **My Winter Car**.

Feel rev-limiter pulses, wheelspin, locked brakes and road bumps through an Xbox/XInput controller. The mod also adds right-stick camera control, R3 recentering, and adjustable vibration and camera settings.

## Features

- Rev-limiter vibration
- Wheelspin and sliding feedback
- Brake lockup feedback
- Bumps and uneven-road feedback
- Adjustable master intensity and per-effect intensity
- Individual vibration test buttons
- Right-stick camera control
- R3 camera recentering
- Adjustable camera sensitivity, deadzone and vertical inversion
- Settings and diagnostics in **English, Brazilian Portuguese and Russian**
- Does not modify save files

## Requirements

- **My Winter Car** on Windows
- **MSCLoader for My Winter Car** — tested with 1.4.2
- Xbox/XInput controller with vibration support

MSCLoader: https://www.nexusmods.com/mywintercar/mods/3

## Installation

1. Close the game and install MSCLoader if needed.
2. Download and extract the mod archive.
3. Copy **RivettRumble.dll** into the **Mods** folder used by MSCLoader.
4. If the DLL is already there, replace it. Do not keep a second renamed copy.
5. Start My Winter Car, load a save and open **My Vibration Gamepad** in the mod settings.
6. Connect your controller, use the vibration test buttons and adjust the settings.

> The DLL keeps its original internal filename, **RivettRumble.dll**, for continuity with earlier builds. The mod appears in game as **My Vibration Gamepad**.

## Compatibility

In-game testing was performed with an Xbox controller and the Corris Rivett. Other vehicles and XInput-compatible controllers may work, but have not all been individually verified.

The mod uses the controller's two main rumble motors, not trigger motors. Other mods that change camera input or controller vibration may conflict.

## Troubleshooting

If there is no vibration:

- Check that the controller is detected through XInput.
- Keep the game window in focus.
- Load a save before testing vehicle effects.
- Use the vibration test buttons in the mod settings.
- Increase the camera deadzone if the view drifts.

## Uninstall

Close the game and remove **RivettRumble.dll** from the MSCLoader Mods folder.
